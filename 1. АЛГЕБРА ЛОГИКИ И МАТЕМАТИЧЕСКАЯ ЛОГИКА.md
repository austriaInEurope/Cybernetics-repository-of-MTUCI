
#1. Логика и алгебра логики

**Логика** изучает способы построения и проверки рассуждений.

Выделяют:

- **формальную логику**;
    
- **математическую логику**.
    

Одним из основателей алгебры логики был **Жорж Буль** — английский математик и логик. Его подход позволил описывать логические операции с помощью математических символов и правил. Идеи Буля стали основой булевой алгебры, которая применяется в математической логике и информатике.

---

# 2. Формальная система

Окружающий мир или некоторую рассматриваемую область можно представить в виде математической модели. Для формального описания используется **формальная система**.

Она записывается:

```text
ФС = <V, F, A, R>
```

где:

- `V` — **алфавит**, множество допустимых символов;
    
- `F` — множество **правильно построенных формул**;
    
- `A` — множество **аксиом**;
    
- `R` — множество **правил вывода**.
    

### Алфавит `V`

Алфавит определяет, какие символы можно использовать в системе.

Например:

```text
V = {0, 1, ..., 9, +, -, /, ×, ...}
```

### Правильно построенные формулы `F`

Из символов алфавита строятся выражения. Но не любое сочетание символов является правильной формулой. `F` — это множество выражений, которые соответствуют правилам построения данной системы.

### Аксиомы `A`

**Аксиома** — исходное положение, которое принимается в формальной системе.

Например:

```text
S(.) = 1
```

В лекции эта запись рассматривается как аксиома.

### Правила вывода `R`

Правила вывода позволяют из уже известных положений получать новые.

Например:

```text
S(.) = 1
```

затем по правилу вывода:

```text
S(S(.)) = 2
```

и далее:

```text
S(S(S(.))) = 3
```

Таким образом, формальная система задаёт строгие правила: **какие символы использовать, какие формулы считать правильными, с чего начинать и как получать новые формулы**.

# 3. Математическая логика и логические значения

**Математическая логика** — формальная система, в которой используются специальные символы для представления логических значений и операций.

Основные логические значения:

```text
true  — истина
false — ложь
```

Также используются:

```text
1 — истина
0 — ложь
```

или обозначения:

```text
t — истина
f — ложь
```

Основные логические операции:

```text
∧ — И
∨ — ИЛИ
¬ — НЕ
```

То есть математическая логика позволяет заменить словесное описание логических действий формальными символами.

---

# 4. Утверждения и универсум

## Утверждение

**Утверждение** — это высказывание, для которого можно определить истинность или ложность.

Например:

```text
«Медведь красный»
«Дождь идёт»
«IEEE — сообщество инженеров»
```

являются утверждениями.

А:

```text
«Какие кеды»
«Автомобиль»
```

в рамках лекции не рассматриваются как утверждения, поскольку для них нельзя однозначно определить значение `true` или `false`.

Утверждение можно обозначить переменной:

```text
A
```

и присвоить ей логическое значение:

```text
A = true
```

или:

```text
A = false
```

Таким образом, в рассматриваемой двузначной логике утверждение имеет одно из двух значений:

```text
true / false
```

---

## Универсум `U`

**Универсум `U`** — это множество объектов, которые рассматриваются в рамках конкретного рассуждения.

Например, если рассматриваются числа:

```text
U = {0, 1, 2, 3, ...}
```

Если рассматриваются студенты определённой группы:

```text
U = {все студенты группы}
```

То есть `U` определяет **область объектов, о которых идёт рассуждение**.

Важно: универсум не обязательно означает всю Вселенную. Это выбранная область объектов.

Утверждения также рассматриваются относительно определённой области.

Например:

```text
U = {все медведи}
```

и:

```text
A = «Медведь красный»
```

Здесь утверждение рассматривается относительно соответствующего универсума и смысла утверждения.

# 5. Основные законы логики

## Закон тождества

Формула:

```text
A = A
```

Смысл:

> А есть А.

Высказывание должно быть тождественно самому себе.

---

## Закон исключённого третьего

Для утверждения `A` рассматриваются два варианта:

```text
A
```

или:

```text
¬A
```

В рассматриваемой двузначной логике утверждение либо истинно, либо ложно.

То есть используются два значения:

```text
true
false
```

Третьего значения между ними нет.

Например:

```text
A = «Сегодня идёт дождь»
```

Тогда:

```text
A  = «Сегодня идёт дождь»
¬A = «Сегодня дождь не идёт»
```

---

## Противоречие

В лекции рассматривается выражение:

```text
A ∧ ¬A
```

Оно означает:

> `A` и одновременно `не-A`.

Например, если:

```text
A = «Сегодня идёт дождь»
```

то:

```text
¬A = «Сегодня дождь не идёт»
```

а:

```text
A ∧ ¬A
```

означает одновременное утверждение обоих высказываний.

В исходном материале также была запись:

```text
A ∧ ¬A = 1
```

Но в самой лекции отмечено, что эта запись требует уточнения, поскольку ранее `1` обозначалась как истина. Поэтому эту конкретную запись не следует заучивать без дополнительного объяснения.

# 6. Логические операции и отрицание

Основные операции:

```text
∧ — И
∨ — ИЛИ
¬ — НЕ
```

### Отрицание

**Отрицание** утверждения `A` обозначается:

```text
¬A
```

Оно меняет логическое значение утверждения на противоположное:

```text
A = true  → ¬A = false
A = false → ¬A = true
```

Например:

```text
A = «Медведь красный»
```

тогда:

```text
¬A = «Медведь не красный»
```

Таким образом, отрицание превращает истину в ложь, а ложь — в истину.

# 7. Логические функции

**Логическая функция** принимает одно или несколько логических значений и возвращает логическое значение.

Для одной переменной:

```text
x → f(x)
```

Для двух переменных:

```text
x, y → f(x, y)
```

В общем случае:

```text
x₁, x₂, ..., xₙ → f(x₁, x₂, ..., xₙ)
```

То есть на вход функции поступают логические значения, а результатом также является логическое значение.

Количество аргументов определяет количество переменных функции.

---

# 8. Количество логических функций

Пусть есть `n` логических переменных.

Каждая переменная может иметь два значения:

```text
0 или 1
```

Поэтому количество возможных наборов входных значений равно:

```text
2ⁿ
```

Например, для двух переменных:

```text
2² = 4
```

Возможные наборы:

```text
00
01
10
11
```

---

Каждому набору входных значений логическая функция может поставить в соответствие одно из двух значений:

```text
0 или 1
```

Поэтому общее количество различных логических функций от `n` переменных равно:

```text
2^(2ⁿ)
```

### Примеры

Для одной переменной:

```text
2^(2¹) = 2² = 4
```

Значит, существует **4 логические функции от одной переменной**.

Для двух переменных:

```text
2^(2²) = 2⁴ = 16
```

Значит, существует **16 логических функций от двух переменных**.

Для трёх переменных:

```text
2^(2³) = 2⁸ = 256
```

Значит, существует **256 логических функций от трёх переменных**.

# 9. Как связаны основные понятия

Основную логику лекции можно представить одной цепочкой:

```text
Логика
↓
Математическая логика
↓
Формальная система
↓
Символы и формулы
↓
Логические утверждения
↓
true / false
↓
Логические операции
∧, ∨, ¬
↓
Логические функции
↓
2^(2ⁿ) функций от n переменных
```

При этом **универсум `U`** определяет область объектов, о которых идёт рассуждение.
